/login
  • Poster slot. The left half of every screen is a campaign slot fed from the CMS (image, eyebrow, headline, copy, CTA). Marketing can swap it per screen without a deploy. Sign in rotates up to 3 slides.
  • Reduced header. Auth screens drop the mega-menu: only the logo, "Continue shopping" and Help. Fewer exits while someone is typing a password; the poster still gets people back to the shop.
  • Promotion follows intent. Sign in = new collection / private sale. Create account = welcome offer card. Forgot/reset = a calm still life (people are stressed here, so no hard sell). Success screens = next step + code.
  • Mobile (≤1024px). The poster becomes a banner above the form so the promotion survives. On the forgot/reset screens it shrinks to a one-line strip so the form stays above the fold.
  • Forgot flow. /forgotpassword (email) → "Check your inbox" (masked email, resend timer) → email link → /forgot-password?token= (new password, account email shown read-only) → "Password updated". An invalid or used token goes to "Link expired".
  • Security copy. "If an account exists for this email…" never confirms whether an email is registered. Reset signs out other devices.
  • Fields match the current API (first/last name, email, password, confirm, terms). The newsletter opt-in, welcome code and "remember me" need backend support before going live.
  • Try it. Submit empty forms to see validation. Type in the password fields to see the strength meter. Submitting the forgot form goes to Check inbox.
